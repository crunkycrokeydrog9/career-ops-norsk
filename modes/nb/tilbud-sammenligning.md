# Modus: tilbud-sammenligning — Sammenligning av flere tilbud

Scorematrise med 10 vektede dimensjoner:

| Dimensjon | Vekt | Kriterier 1-5 |
|-----------|------|---------------|
| Nordstjerne-tilpasning | 25% | 5=eksakt målrolle, 1=ikke relatert |
| CV-match | 15% | 5=90%+ match, 1=<40% match |
| Nivå (senior+) | 15% | 5=staff+, 4=senior, 3=mid-senior, 2=mid, 1=junior |
| Estimert kompensasjon | 10% | 5=topp kvartil, 1=under marked |
| Vekstbane | 10% | 5=tydelig vei til neste nivå, 1=blindvei |
| Remote-kvalitet | 5% | 5=full remote asynkront, 1=kun på kontoret |
| Selskapsrykte | 5% | 5=topp arbeidsgiver, 1=røde flagg |
| Tech stack-modernitet | 5% | 5=cutting edge AI/ML, 1=legacy |
| Hastighet til tilbud | 5% | 5=rask prosess, 1=6+ måneder |
| Kultursignaler | 5% | 5=byggekultur, 1=byråkratisk |

**Norskspesifikke vurderinger:**
- OTP-sats (2% vs 7% er enorm forskjell over tid)
- Tariffavtale kan bety forutsigbar lønnsutvikling
- Fleksibilitet/hjemmekontor-policy
- Bedriftens størrelse i norsk kontekst (SMB vs konsern)

For hvert tilbud: score i hver dimensjon, vektet totalscore.
Endelig rangering + anbefaling med time-to-offer-vurderinger.

Be brukeren om tilbudene hvis de ikke er i kontekst. Kan være tekst, URL-er, eller referanser til allerede evaluerte tilbud i trackeren.

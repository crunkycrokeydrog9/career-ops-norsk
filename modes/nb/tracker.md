# Modus: tracker — Søknadsoversikt

Les og vis `data/applications.md`.

**Tracker-format:**
```markdown
| # | Dato | Selskap | Rolle | Score | Status | PDF | Rapport |
```

Mulige statuser: `Evaluert` → `Søkt` → `Besvart` → `Kontaktet` → `Intervju` → `Tilbud` / `Avslått` / `Forkastet` / `HOPP OVER`

- `Søkt` = kandidaten sendte sin søknad
- `Besvart` = en rekrutterer/selskap tok kontakt og kandidaten svarte (innkommende)
- `Kontaktet` = kandidaten tok proaktivt kontakt med noen i selskapet (utgående, f.eks. LinkedIn-trekk)

Hvis brukeren ber om å oppdatere en status, rediger den tilsvarende raden.

Vis også statistikk:
- Totalt antall søknader
- Per status
- Gjennomsnittlig score
- % med generert PDF
- % med generert rapport

# Modus: opplaering — Evaluering av opplæring/kurs

For hvert kurs/sertifisering kandidaten spør om, evaluer 6 dimensjoner:

| Dimensjon | Hva den evaluerer |
|-----------|-------------------|
| Nordstjerne-tilpasning | Bringer det nærmere eller fjernere fra målet? |
| Rekrutterersignal | Hva tenker rekrutteringsledere når de ser dette på en CV? |
| Tid og innsats | Uker × timer/uke |
| Alternativkostnad | Hva kan ikke kandidaten gjøre i løpet av den tiden? |
| Risiko | Utdatert innhold? Svakt merkenavn? For grunnleggende? |
| Porteføljeleveranse | Produserer det en demonstrerbar artefakt? |

## Dommer

- **GJØR DET** → plan for 4-12 uker med ukentlige leveranser og resultattavle
- **IKKE GJØR DET** → bedre alternativ med begrunnelse
- **GJØR MED TIDSBOKS** (maks X uker) → komprimert plan, bare det essensielle
